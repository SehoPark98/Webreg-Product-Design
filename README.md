# UCI WebReg Redesign – Product Design Project

A UX/UI redesign project focused on improving the course registration experience for students using UCI WebReg.

The project was based on the following user story:

> "As a student, I want to keep track of my classes and prerequisites in one place so that I can enroll in classes smoothly and manage my time more efficiently."

## Project Goals

The redesign focused on making course registration more intuitive by:

- Displaying prerequisite courses directly during enrollment
- Showing enrolled classes in a visual timetable
- Helping students identify schedule conflicts before registration
- Improving navigation and overall usability
- Incorporating accessibility considerations into the interface

## Design Process

Our team followed a product design workflow that included:

1. User story development
2. Expert usability review
3. Low-fidelity wireframes
4. High-fidelity mockups
5. Interactive prototyping in Figma
6. Accessibility and usability review

## Key Features

### Prerequisite Visibility
Prerequisite courses are displayed directly alongside course enrollment information, reducing the need to switch between pages.

### Schedule Visualization
Registered courses are shown in a timetable view to help students immediately identify scheduling conflicts.

### Improved Information Hierarchy
The redesigned interface organizes enrollment information, deadlines, course details, and scheduling information more clearly.
